# Project Skills

Skill yang relevan untuk project ini:

- `excel-to-csv`: konversi spreadsheet jadwal ke `data/schedule_tracker.csv`.
- `validate-schedule`: validasi CSV jadwal sebelum automation dijalankan.
- `login-profile`: refresh login Gmail persistent Chrome profile.
- `run-schedule`: menjalankan batch scheduler Playwright.

Skill tambahan yang ada di folder ini:

- `ponytail`: panduan perubahan kode minimal/YAGNI.
- `taste-skill`: panduan frontend marketing/landing page, bukan dashboard operasional.

Catatan: setelah mengubah file skill atau `opencode.json`, restart opencode agar konfigurasi baru terbaca.
